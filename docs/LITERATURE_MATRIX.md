## PARTNR action and graph audit

The published Appendix A.7.1 grounds privileged partial detections in panoptic and simulator relations and describes graph updates using previous actions and their results. For a successful placement, the appendix describes replacing the held relation with a relation to the destination furniture. Appendix A.7.2 describes the ConceptGraphs variant. [Paper appendix](https://arxiv.org/html/2411.00081#A7)

At revision `ddfff19f4b6c098a31edea4d19e7b75db72433c2`, the released world-model README specifies ground-truth segmentation in both graphs and RGB-D localization and reassociation for the non-privileged variant. The planner passes its `action_results` into the appropriate graph update. The ConceptGraphs own-action update checks for a success string. On placement it removes the held object by default, or moves it into the destination graph relation when configured to keep it. This audit covers those released graph paths. ## Comparisons this study can support

- **Outcome uncertainty.** Use observed placement failures alongside matching intended commands. Measure false containment assignments when visible evidence contradicts the command. Keep labels for obscured intermediate transitions unknown.
- **Distributed evidence.** Change the permitted sender, delivery deadline or association factor while preserving the original private histories. Compare the exact and particle filters and learned visual factors on equal inputs and costs. Credit methods based on measured improvements over these controls.
- **Insufficient evidence.** In paired F6 variants, swap hidden evaluator truth while holding the complete permitted inputs and randomness fixed. Compare forecast equality, error and coverage with a resolvable control. A correct inspection request and an inspection that actually resolves ambiguity have separate measures.
- **Execution.** Fix the motor executor in the primary memory comparison. Use the matched motor study to check ACT and SmolVLA separately, with physical competence reported only after attended execution evidence.
